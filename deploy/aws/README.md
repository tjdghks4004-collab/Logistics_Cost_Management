# AWS는 선택 가능한 운영 방식

개발 자체에 AWS 서버가 필요한 것은 아닙니다. 현재 개발 환경에서 기능을 계속 만들고 테스트할 수 있습니다. AWS를 사용한 상시 운영을 선택하면 AWS의 서버·스토리지 등 사용료가 별도로 발생합니다. 다른 운영 시스템의 호스팅을 조사하거나 재사용하지 않습니다. 현재 AWS 연결·배포·유료 자원 생성은 하지 않았습니다.

사용자 확인 상태:

- AWS 계정 있음. 이 개발 환경에는 AWS 연결이 아직 관측되지 않음.
- 사용자 수는 SCM팀 2~3명.
- 독립 AWS 서버를 선택했으며 예상 비용을 확인한 뒤 진행하기로 함. 월 예산과 자원 생성 승인은 미확정. 서울 리전은 검토 기본값이며 확정 배포가 아님.
- 당분간 실제 자료는 업로드하지 않음. 기존 라벨 운영 서비스는 변경하지 않음.

## 요금 확인부터 진행

AWS 계정을 연결한 CLI v2 환경에서 아래 명령을 실행하면 현재 서울 리전의 소규모 Linux 번들 월요금을 조회할 수 있습니다.

```sh
python3 deploy/aws/check-costs.py --region ap-northeast-2
```

이 도구는 STS 신원 확인과 Lightsail get-bundles 두 종류의 읽기 요청만 허용합니다. 서버·버킷·IAM 사용자·접속키·방화벽을 만들거나 바꾸지 않습니다. 계정번호·자격증명 값은 출력하지 않습니다. 다른 AWS 리전은 --region으로 지정할 수 있습니다.

가격은 API가 반환한 실제 번들 USD 금액만 표시합니다. 원화 금액이나 최종 청구액을 임의로 확정하지 않습니다. S3 백업 저장량·요청량, 스냅샷, 추가 데이터 전송, 도메인, 세금·환율과 해당 계정의 프로모션/크레딧은 별도 확인해야 합니다. IPv6 전용 번들은 public IPv4 구성과 구분하여 확인하세요. 최신 공식 요금은 https://aws.amazon.com/lightsail/pricing/ 및 https://aws.amazon.com/s3/pricing/ 에서 확인할 수 있습니다.

AWS 연결에는 이 환경의 설정에서 AWS 신원 연결을 사용하세요. 프로필이 제공되면 해당 연결의 프로필과 설정 경로로 CLI를 실행합니다. 채팅·저장소·스크립트에 접속키나 비밀번호를 넣지 않습니다. 제한 네트워크에서는 서울 조회용으로 sts.ap-northeast-2.amazonaws.com과 lightsail.ap-northeast-2.amazonaws.com 접근이 필요합니다. 현재 실제 AWS API 호출은 검증하지 못했습니다.

## 운영 선택

- 현재 개발 환경: 기능 개발과 임시 검증을 계속 진행. 상시 운영 주소나 영구 호스팅을 보장하는 배포는 아님.
- AWS 신규 운영: 실시간 요금과 예산을 확인한 후 서버 1대 + 영구 DB 저장 + 별도 백업을 배포. 관리자 계정과 HTTPS를 함께 구성.

실제 AWS 구성을 선택하기 전에는 생성 작업을 실행하지 않습니다. 기존 Docker 배포 파일과 DEPLOYMENT.md는 호스팅 선택 후 사용할 수 있습니다.

구체적인 구성과 산정 가정은 [비용 검토안](PLAN.md)에 정리했습니다. 이 산정은 실시간 가격 조회 결과가 아닙니다.
