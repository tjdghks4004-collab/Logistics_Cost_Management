# 독립 AWS 개발 사이트 — 비용 검토안

상태: 사용자는 ‘독립 AWS 서버 — 예상 비용 확인 후 진행’을 선택했습니다. 자원 생성·요금 발생 승인은 아직 받지 않았습니다. 현재 AWS 연결, 실시간 번들 조회, 공인 IP, 도메인, 외부 HTTPS 사이트는 없습니다.

## 제안 구성

- 서울(ap-northeast-2) Lightsail Linux 1대: RAM 2GB, public IPv4 포함 번들을 우선 검토합니다. SCM팀 2~3명, 단일 Node 앱+SQLite+HTTPS 프록시를 대상으로 합니다. 큰 Excel 파일은 실제 데이터 검증 후 성능을 판단합니다.
- DB는 앱 전용 영구 볼륨에 저장합니다. 다른 운영 서비스의 서버·DB·포트·도메인을 재사용하지 않습니다.
- S3는 별도 비공개 백업 버킷으로 사용합니다. 기존 일일 검증 백업을 업로드하고 30일 보존하는 구성을 검토합니다. 실제 업로드·예약 실행은 아직 연결하지 않았습니다.
- 애플리케이션 포트는 서버 내부에서만 열고, 팀원의 브라우저는 별도 HTTPS 주소로 접속합니다. 관리자 비밀번호는 설치 후 직접 설정하며 미리 만든 계정은 없습니다.
- RDS·로드밸런서·외부 AI API는 이 초기 구성에 포함하지 않습니다.

## 산정용 가정 — 현재 요금으로 검증되지 않음

| 구성 | 월 USD 가정 | 비고 |
|---|---:|---|
| 2GB Linux/IPv4 번들 | 12 | 가격·서울 번들 공급 여부를 실제 get-bundles 응답으로 재확인해야 함 |
| 소량 S3 백업+요청 | 1 | 전체 보관량 약 10GB 이내를 가정한 예비비. 사용량에 따라 변동 |
| 가정 합계 | 13 | 도메인·추가 스냅샷·전송 초과·기타 자원 제외 |

환율 1달러=1,500원과 세금 10%를 단순 적용하면 약 21,450원/월입니다. 이는 견적 산식이며 현재 환율·확정 청구액이 아닙니다. **월 2만~3만 원을 검토 예산으로 제안**하며, 예산 알림이 지출을 자동으로 차단하는 기능은 아닙니다. 신규 무료 혜택·크레딧은 적용을 보장할 수 없어 산정하지 않았습니다. 도메인 구입비와 추가 사용량은 별도입니다.

최신 공식 요금: https://aws.amazon.com/lightsail/pricing/ , https://aws.amazon.com/s3/pricing/

## 실제 조회와 생성의 경계

1. 환경 설정에서 이 프로젝트에 사용할 AWS 계정을 연결합니다. 채팅에 키·비밀번호를 보내지 않습니다.
2. AWS 가격/신원 확인용 네트워크 설정을 저장·Publish하고, 새 런타임에서 연결 준비 상태와 프로필을 확인합니다.
3. AWS CLI가 준비되면 `python3 deploy/aws/check-costs.py --region ap-northeast-2`로 STS와 Lightsail 번들 가격을 읽기만 합니다.
4. 실제 번들 ID·월요금·백업 가정·월 예산을 사용자에게 제시합니다.
5. 사용자가 비용을 확인하고 생성 범위를 승인한 뒤에만 신규 자원을 생성합니다. 현재는 어떤 AWS 자원도 생성하지 않았습니다.

환경 설정의 도메인 허용은 AWS 계정 연결이나 배포 자체가 아닙니다. 저장·Publish는 환경 설정을 적용하는 과정이며, 사이트 공개를 의미하지 않습니다.
